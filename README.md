# 📚 Repositório — Projeto Final do Curso de ADS

Bem-vindo(a) ao repositório do meu **Projeto Final do curso de Análise e Desenvolvimento de Sistemas (ADS)**!

## 🎯 Sobre este repositório

Este repositório do GitHub é destinado à organização, documentação e acompanhamento das atividades desenvolvidas ao longo dos Sprints do meu projeto final do curso.

Cada arquivo `.md` (Markdown) corresponde a uma atividade específica, contendo suas respectivas informações, documentações, códigos, registros e entregas.

## 📂 Organização

As atividades estão organizadas individualmente em arquivos Markdown, facilitando a identificação, consulta e acompanhamento de cada etapa do projeto.

## 🚀 Objetivo

Manter todas as atividades dos Sprints centralizadas em um único ambiente, garantindo organização, versionamento e acompanhamento da evolução do projeto durante seu desenvolvimento.
