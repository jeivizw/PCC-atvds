# Tarefa 07 — Identificação de Entidades e Atributos do Banco de Dados

**Projeto:** Industrial Control Tower  
**Squad:** FNCS  
**Sprint:** 1 — Estruturação e Arquitetura do Sistema

## Objetivo

Identificar e definir as entidades, atributos e tipos de dados necessários para estruturar o banco de dados do Industrial Control Tower.

## Ferramenta utilizada

- **dbdiagram.io:** ferramenta utilizada para organizar e representar a estrutura inicial do banco de dados.

## Entidades identificadas

Foram identificadas 14 entidades para representar as principais informações do sistema:

| Entidade | Descrição |
|---|---|
| departamentos | Setores da indústria |
| usuarios | Usuários da plataforma |
| materiais | Matérias-primas e insumos |
| estoques | Quantidades disponíveis de materiais |
| movimentacoes_estoque | Entradas e saídas de materiais |
| clientes | Cadastro de clientes |
| produtos | Produtos comercializados |
| pedidos | Pedidos realizados |
| itens_pedido | Produtos e quantidades dos pedidos |
| linhas_producao | Linhas de produção industriais |
| ordens_producao | Planejamento das ordens de produção |
| registros_producao | Registros de produção realizada |
| entregas | Informações sobre entregas |
| alertas | Registro de situações e riscos operacionais |
